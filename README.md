# ⚡ Asad Uz Zaman — Portfolio

A futuristic, dark-themed portfolio website built with pure HTML, CSS & JavaScript.

## 🔗 Live

**[View Live →](https://dragneel-leo.github.io/portfolio/)**

## ✨ Features

- 🌌 Particle constellation background
- ⌨️ Typewriter role animation
- 🃏 Glassmorphism cards with 3D tilt
- 🌈 Animated gradient text & neon glows
- 📊 Animated skill bars & stat counters
- 🎯 Holographic avatar frame with scanline
- ⏳ Glowing vertical timeline
- 📱 Fully responsive — mobile-first
- ♿ Reduced-motion & touch-device support
- 🚀 Zero dependencies — no build step

## 🛠 Tech

| File | Purpose |
|------|---------|
| `index.html` | Structure & SEO meta tags |
| `style.css` | Styling, animations, responsive design |
| `script.js` | Interactivity, data, particle system |
| `404.html` | Custom error page |
| `avatar.jpg` | Profile photo |

## 📦 Deploy

Static site — just push and enable GitHub Pages:

1. Go to **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / root
4. Save — your site will be live!
